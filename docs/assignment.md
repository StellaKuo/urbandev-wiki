# 生成式 AI 課程作業：建立 AGENTS.md

## 專案主題與動機
UrbanDev Wiki 是都市更新、危老重建與土地開發知識庫。選擇熟悉的專業主題，讓 AI 協助將知識整理成可閱讀、可搜尋的文章。

## 作業目標
不只是完成一個網頁，更要建立可重複使用的開發規範。AI 閱讀 `AGENTS.md` 後，應知道文章格式、檔案位置、視覺風格、禁止事項與驗證方法。

## 網站成果
首頁提供文章卡片、分類篩選、關鍵字搜尋及閱讀對話框；純 HTML/CSS/JS，不需後端或 API 金鑰，支援本機直接開啟與 GitHub Pages。

## AI 協作示範：依規範批次擴充文章
- 原有文章：5 篇，本次擴充至 39 篇。
- 指令：『先閱讀 AGENTS.md，依現有分類批次新增都市更新、危老重建、土地開發入門文章；不要更動既有文章與版型；執行測試。』
- 依規範新增 34 篇：只編輯 `data/articles.json`，每篇均具分類、摘要、三個段落、日期與參考入口。
- 執行 `npm run check`：驗證 JSON 結構、ID 唯一性、來源及產生檔同步。
- 產生 `assets/js/articles-data.js`，網站可在本機直接開啟，不再依賴 `fetch`。

## 內容品質限制
本版文章以入門知識整理為主，來源目前多為官方法規及主管機關網站入口，尚未逐篇核對特定條文與地方自治規定。正式提供專業諮詢前，應補充個別條文連結、更新日期與專家審閱。

## 反思
原始版本依賴 fetch 讀取 JSON，直接雙擊 HTML 時可能因瀏覽器安全限制而失敗。修正版將 JSON 作為唯一編輯來源，透過腳本產生可直接載入的 JavaScript 資料檔。這使『資料維護』與『網頁執行』分離，也能透過自動化測試降低 AI 改動造成的錯誤。規範仍無法代替人工核實法規、跨瀏覽器測試與正式部署。
